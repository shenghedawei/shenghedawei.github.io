香港学习 · 2026-09 · 方案详解

赴港课堂 AI 记录方案详解HK Class AI Recording — The Full Plan

目标：2027 年 1 月赴中国香港珠海学院读研（中文授课，每天上课 >6 小时），课堂上 AI 全程记录 → 自动整理归纳 → 便于查询与期末复习。原则：核心处理本地化，数据不出本机。Goal: record every HK class with AI, auto-organize for review. Principle: local processing, data never leaves the machine.

设备清单与分工Gear & Roles

Insta360 Mic Pro（课堂录音主力）：发射器自带 32GB 存储，独立内录约 60h / 续航 10h，领夹级人声收音，不占手机、不依赖 WiFi。Insta360 Mic Pro: 32GB onboard, ~60h record / 10h battery, clip-on, phone-free.

Mac Mini M4（处理层主力）：Apple Silicon 本地跑 Whisper 转写 + 本地 LLM 归纳。Mac Mini M4: local Whisper transcription + local LLM summarization.

大疆 Mic Mini 2（备用领夹麦）、小米 18 Pro Max（飞行模式录音）、MacBook Pro 2017（日常轻办公）、安卓平板（复习看笔记）、15.6" 便携屏（M4 显示屏）。DJI Mic Mini 2 (backup), phone (airplane-mode record), MacBook 2017 (light office), Android tablet (review), 15.6" portable monitor.

需购买清单What to Buy

经盘点，领夹麦、录音设备、便携屏、处理机均已具备，当前没有任何必须新买的设备。After inventory: mic, recorder, portable monitor and M4 are all owned — nothing must be bought.

每日工作流Daily Workflow

① 课前：Mic Pro 夹衣领 → 开机独立内录；② 课中：平板可装实时转写 App 看字幕（走云端时），纯本地方案课后处理；③ 课后回住处：音频经 Type-C 导出到 M4 → Whisper 转写（中文强）→ 本地 LLM 归纳成结构化笔记（章节 / 重点 / 疑点 / 提纲 / 思维导图）→ 存可搜索笔记；④ 复习：平板 / 笔记本 / 手机随时关键词搜索。① Clip & record. ② Optional live caption. ③ Export to M4 → Whisper → LLM notes. ④ Search anywhere.

Mac Mini M4 本地部署Local M4 Setup

转写用 openai-whisper（或 whisper.cpp，Apple Silicon 原生更快）；归纳用 Ollama 跑 Qwen3-VL 本地推理。流程：课堂录音 → Whisper 转写中文 → 喂给本地 LLM → 输出结构化笔记，可写成脚本批量处理整周音频。Transcribe with Whisper; summarize with local Qwen3-VL via Ollama. Chain both in a script to batch a week's audio.

注意事项Notes

· 收音：Mic Pro 夹衣领、距嘴 15–20cm，人声最干净；· 合规：录音前跟老师知会一声（香港课堂隐私礼仪）；· 备份：笔记多重备份（iCloud / WPS 知识库 / 移动硬盘）；· 电量：M4 在宿舍插电，便携屏选 Type-C 一线连。Mic 15–20cm from mouth; inform the teacher before recording; multi-backup notes; M4 on power at dorm.
